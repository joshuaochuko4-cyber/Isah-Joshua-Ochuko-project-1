📌 Project Overview

This project focused on cleaning and preparing a raw e-commerce dataset to improve data quality and ensure accurate analysis. The dataset contained inconsistencies such as missing values, duplicate records, formatting issues, and inconsistent text entries which were corrected using Excel data cleaning techniques.

⸻

🎯 Objective

To identify and fix data quality issues by handling missing values, removing duplicates, correcting data formats, and standardizing records to create a clean and analysis-ready dataset.

⸻

🛠️ Tools Used

* Microsoft Excel
* Excel Functions
* Data Cleaning Techniques

⸻

🔧 Data Cleaning Process

* Identified and handled missing/null values
* Removed duplicate records
* Standardized text formatting using Excel functions
* Corrected date and numeric formats
* Removed extra spaces and inconsistent entries
* Validated dataset consistency and structure
* Converted dataset into a clean and analysis-ready table

⸻

💡 Key Outcome

The cleaned dataset improved data consistency, accuracy, and reliability, making it suitable for exploratory analysis and dashboard reporting.
